## Главная идея

**Локальные LLM** — те же облачные нейросети, развёрнутые на твоём устройстве: бесплатный инференс после покупки железа, полная приватность, работа без интернета.

## Почему не облако

| Проблема | Детали |
|----------|--------|
| **Дорого** | подписки $200/мес; Mac Mini окупается за пару лет |
| **Нет приватности** | данные уходят на сервер |
| **Зависимость от сети** | нет WiFi — нет ассистента |
| **Цена растёт с нагрузкой** | чем больше запросов, тем выше счёт |

Локально: платишь за железо один раз, масштабируешь инференс бесплатно.

## Как устроена LLM

```
Запрос → [Input Layer] → [Hidden Layers × N] → [Output Layer] → Ответ
                              ↑ self-attention / transformers
```

- **Forward propagation** — предсказание следующего токена (инференс).
- **Backward propagation** — обучение: корректировка → перестройка весов.

**Термины:** **веса** (числовые связи), **нода** (нейрон), **layer** (уровень), **параметры** (совокупность весов; 7B = 7 млрд).

## Параметры и память

| Размер | VRAM (fp16) | Железо |
|--------|-------------|--------|
| 1B | ~2 GB | CPU ноутбук |
| 3B | ~6 GB | слабая GPU / Intel iGPU |
| 7B | ~14 GB | дискретная видюха |
| 13B | ~26 GB | RTX 3090/4090 |
| 70B | ~140 GB | Mac Studio / кластер |

**Формула:** параметры × 2 байта (fp16) ≈ VRAM в гигабайтах.

## Квантизация

Уменьшение точности весов для экономии памяти:

```
float16 (2 байта) → INT8 (1 байт)  → экономия ×2
float16 (2 байта) → INT4 (0.5 байта) → экономия ×4
```

**Пример 70B:** fp16 = 140 GB; **Q4** ≈ 35 GB; **Q8** ≈ 70 GB.

Обозначения в именах: `Q4_K_M`, `Q8_0`, `IQ3_XS`. **Q4–Q6** — рабочий баланс; ниже Q4 — заметная деградация.

## Локальная vs облачная

| | Локальная | Облачная |
|---|-----------|----------|
| Скорость | медленнее | быстрее |
| Качество | ниже (7B ≈ GPT-3.5) | выше |
| Цена | разово (железо) | ежемесячно |
| Приватность | полная | нет |
| Интернет | не нужен | нужен |

Для простых внутренних задач **7B** часто достаточно.

## Use cases

1. **Offline-ассистент** — без интернета.
2. **Суммаризация документов** — старый ПК с GPU в закрытом контуре.
3. **Автодополнение кода** — код не уходит на сервер.
4. **Чат-бот** — данные не утекают.
5. **Классификация** — закрытые документы без облака.

## RAG + локальная LLM

```
Документы → Embedding → Векторная БД
                              ↓
Запрос → Поиск → Контекст + LLM → Ответ
```

**Зачем связка:**

- компенсирует устаревшие знания опенсорс-моделей (лаг 3–12 мес);
- снижает галлюцинации — ответ привязан к документам;
- расширяет знания без дообучения.

## Практический вывод

Локальная LLM — не замена облаку, а **другой trade-off**: приватность и нулевая маржинальная стоимость запроса vs скорость и качество.

Выбор модели — под **VRAM** и задачу; квантизация Q4–Q6 делает крупные модели доступными. **RAG + локальная генерация** — сильная связка для закрытых баз знаний без утечки данных.
