# AI Advent Challenge #8

Репозиторий для ежедневных заданий курса **AI Advent Challenge #8**.  
Стек: **Python**. Каждый будний день — отдельная папка `weeks/week-NN/day-DD/`.

Инструкции для coding agent (Cursor и др.): [AGENTS.md](AGENTS.md).

## Формат курса

| Параметр | Значение |
|----------|----------|
| Длительность | 7 недель × 5 будних дней (35 заданий) |
| Выдача заданий | Пн–Пт, **14:00** |
| Сдача | **Видео + код** (видео — главное доказательство) |
| Отсев | Понедельник 14:00 — не сданы все 5 заданий прошлой недели |
| Сложность | Пн проще, Пт сложнее; недели тоже нарастают |

Код сдавайте через GitHub (этот репозиторий). Видео — на Яндекс.Диск или аналог. Ссылки вносите в **таблицу курса** и дублируйте в [submissions.md](submissions.md).

## Термины

- **Harness / code-assistant** — Cursor, Codex и т.п.: нейросеть помогает писать код.
- **Agent (в приложении)** — вы вызываете LLM по API внутри своего сервиса для пользователя.

Рекомендация курса: максимум через harness; для API в продукте — дешёвые модели.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
# заполнить ключи по мере заданий
```

Работа над заданием дня N:

```bash
cd weeks/week-01/day-01
# код, README дня, затем обновить submissions.md
```
