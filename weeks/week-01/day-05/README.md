# Неделя 1, день 5

## Задание

Один и тот же запрос к LLM на трёх моделях разного уровня:

- слабая — `qwen/qwen3.5-9b`
- средняя — `qwen/qwen3.5-35b-a3b`
- сильная — `qwen/qwen3.7-max`

Замерить время ответа, количество токенов и стоимость. Сравнить качество, скорость и ресурсоёмкость. Выводы формулирует LLM на основании трёх ответов и метрик.

## Результат

На видео: запуск `main.py`, в консоли три ответа на один промпт + блок «СРАВНЕНИЕ» + блок «АНАЛИЗ» + «ССЫЛКИ».

## Запуск

```bash
source .venv/bin/activate
pip install -r weeks/week-01/day-05/requirements.txt
cp .env.example .env   # если ещё нет
# В .env: DOCKHOST_AI_KEY=...

# Все три модели + анализ LLM (основной сценарий)
python weeks/week-01/day-05/main.py

# По одной модели — для монтажа видео
python weeks/week-01/day-05/main.py --weak
python weeks/week-01/day-05/main.py --medium
python weeks/week-01/day-05/main.py --strong

# Только sweep, без 4-го вызова
python weeks/week-01/day-05/main.py --no-analysis

# Свой промпт
python weeks/week-01/day-05/main.py "Твой текст запроса."
```

Переменные окружения — как в [день 1](../day-01/README.md).

## Параметры API

| Вызов | temperature | Назначение |
|-------|-------------|------------|
| 1–3 | 0.7 | Один user-промпт, меняется только модель |
| 4 (анализ) | 0 | Сравнение ответов и рекомендации по моделям (промпт в консоль не выводится) |

Анализ выполняется на средней модели (`qwen/qwen3.5-35b-a3b`).

## Промпт (дефолт в коде)

```
Опыт СССР — не эпитафия, а учебник. Какие уроки мировое пролетарское движение должно извлечь из этого опыта для периода после мировой пролетарской революции? С позиций марксизма, без либеральных штампов. 3–4 урока: к каждому — два-три предложения. Фокус на будущем — что делать, а не пересказ прошлого.
```

## Промпты для видео

**Что проговорить:**

1. Один промпт — единственная переменная: **модель**.
2. Слабая модель: проще, шаблоннее, уроки беднее.
3. Средняя: баланс глубины и скорости.
4. Сильная: точнее формулировки, но дороже и дольше.
5. Блок «СРАВНЕНИЕ» — время, токены, стоимость в рублях.
6. Блок «АНАЛИЗ» — не ручной текст, а выводы модели по реальным ответам.
