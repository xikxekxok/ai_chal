# Неделя 1, день 2

## Задание

Один и тот же запрос к LLM, но с разным уровнем контроля ответа **через параметры API**:

- явный формат — `response_format`
- ограничение длины — `max_tokens`
- условие завершения — `stop`

Сравнить ответы: без ограничений и с ограничениями.

## Результат

На видео: запуск `main.py`, в консоли два ответа на один промпт — свободный текст и короткий JSON с `finish_reason` и числом токенов.

## Запуск

```bash
source .venv/bin/activate
pip install -r weeks/week-01/day-02/requirements.txt
cp .env.example .env   # если ещё нет
# В .env: DOCKHOST_AI_KEY=...

# Сравнение обоих режимов (основной сценарий)
python weeks/week-01/day-02/main.py

# Только без ограничений
python weeks/week-01/day-02/main.py --baseline

# Только с параметрами API
python weeks/week-01/day-02/main.py --controlled

# Свой промпт — оба режима
python weeks/week-01/day-02/main.py "Объясни, что такое REST API: методы, статусы и примеры."
```

Переменные окружения — как в [день 1](../day-01/README.md).

## Параметры API (режим `--controlled`)

| Параметр | Значение | Назначение |
|----------|----------|------------|
| `response_format` | `{"type": "json_object"}` | ответ в JSON |
| `max_tokens` | `80` | лимит длины |
| `stop` | `["---"]` | стоп-последовательность |

User-промпт в обоих режимах **одинаковый**; system-message только для совместимости с `json_object` (требование OpenAI API).

## Промпты для видео

**Дефолтный (в коде):**

```
Перечисли пять полезных советов начинающему Python-разработчику. Для каждого совета дай развёрнутое объяснение с примером.
```

**Альтернативный (через argv):**

```
Объясни, что такое REST API: методы, статусы и примеры использования.
```

**Что проговорить:**

1. Один промпт — два вызова API.
2. Baseline: длинный текст, `finish_reason: stop`.
3. Controlled: JSON, `max_tokens`/`stop`, меньше `completion_tokens`.
4. Контроль ответа — параметрами API, не только текстом промпта.
