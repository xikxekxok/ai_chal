# Неделя 1, день 4

## Задание

Один и тот же запрос к LLM с разными значениями `temperature`:

- `temperature = 0`
- `temperature = 0.7`
- `temperature = 1.2`

Сравнить ответы по точности, креативности и разнообразию. Выводы «для каких задач лучше подходит каждая настройка» формулирует LLM на основании анализа трёх ответов.

## Результат

На видео: запуск `main.py`, в консоли три ответа на один промпт + блок «СРАВНЕНИЕ» + блок «АНАЛИЗ» с рекомендациями от модели.

## Запуск

```bash
source .venv/bin/activate
pip install -r weeks/week-01/day-04/requirements.txt
cp .env.example .env   # если ещё нет
# В .env: DOCKHOST_AI_KEY=...

# Все три температуры + анализ LLM (основной сценарий)
python weeks/week-01/day-04/main.py

# По одной температуре — для монтажа видео
python weeks/week-01/day-04/main.py --temp0
python weeks/week-01/day-04/main.py --temp07
python weeks/week-01/day-04/main.py --temp12

# Только sweep, без 4-го вызова
python weeks/week-01/day-04/main.py --no-analysis

# Свой промпт
python weeks/week-01/day-04/main.py "Придумай три шутки про программистов и капитализм."
```

Переменные окружения — как в [день 1](../day-01/README.md).

## Параметры API

| Вызов | temperature | Назначение |
|-------|-------------|------------|
| 1–3 | 0, 0.7, 1.2 | Один user-промпт, меняется только temperature |
| 4 (анализ) | 0 | Сравнение ответов и рекомендации по задачам |

## Промпт (дефолт в коде)

```
Ты агитатор на митинге в духе марксизма-ленинизма. Придумай три разных лозунга о пролетарской революции против буржуазии. К каждому — одно предложение пояснения. Допустим здоровый юмор, но без оскорблений и призывов к насилию.
```

## Промпты для видео

**Что проговорить:**

1. Один промпт — единственная переменная: `temperature`.
2. `temperature=0`: сухо, шаблонно, предсказуемо.
3. `temperature=0.7`: баланс — живее, но ещё связно.
4. `temperature=1.2`: неожиданнее, разнообразнее, возможен «разгон».
5. Блок «АНАЛИЗ» — не ручной текст, а выводы модели по реальным ответам: точность, креативность, разнообразие и рекомендации по задачам.
