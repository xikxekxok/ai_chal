# Неделя 1, день 3

## Задание

Одна логическая задача — четыре способа рассуждения через API:

1. **Прямой ответ** — задача без дополнительных инструкций
2. **Пошагово** — добавлено «Решай пошагово»
3. **Meta-prompt** — модель сначала составляет промпт для решения, затем решает по нему
4. **Эксперты** — три роли (аналитик, инженер, критик), ответ от каждой

Сравнить: отличаются ли ответы, какой способ точнее.

## Результат

На видео: запуск `main.py`, в консоли промпты, параметры и ответы по каждому способу + блок «СРАВНЕНИЕ».

## Запуск

```bash
source .venv/bin/activate
pip install -r weeks/week-01/day-03/requirements.txt
cp .env.example .env   # если ещё нет
# В .env: DOCKHOST_AI_KEY=...

# Все 4 способа + сравнение (основной сценарий)
python weeks/week-01/day-03/main.py

# По одному способу — для монтажа видео
python weeks/week-01/day-03/main.py --direct
python weeks/week-01/day-03/main.py --step
python weeks/week-01/day-03/main.py --meta
python weeks/week-01/day-03/main.py --experts

# Своя задача (все способы)
python weeks/week-01/day-03/main.py "У вас 8 шаров, один тяжелее. За сколько взвешиваний найти его?"
```

Переменные окружения — как в [день 1](../day-01/README.md).

## Задача (дефолт в коде)

```
Пять машин за пять минут проезжают пять миль. За сколько минут сто машин проедут сто миль? Объясни рассуждение и назови итоговое число минут.
```

**Эталон:** 5 минут (машины едут параллельно; типичная ошибка — «100 минут»).

## Способы рассуждения

| Флаг | API-вызовов | Что меняется |
|------|-------------|--------------|
| `--direct` | 1 | Только текст задачи |
| `--step` | 1 | Задача + «Решай пошагово.» |
| `--meta` | 2 | Генерация промпта → решение по нему |
| `--experts` | 3 | System-роли: аналитик, инженер, критик |

## Промпты для видео

**Что проговорить:**

1. Одна задача — четыре стратегии промпта (не параметры API).
2. `--direct`: быстрый ответ, возможна ошибка «100 минут».
3. `--step`: пошаговое рассуждение, часто точнее.
4. `--meta`: показать сгенерированный промпт и ответ по нему.
5. `--experts`: три акцента — анализ, алгоритм, критика типичных ошибок.
6. Блок «СРАВНЕНИЕ»: эталон 5 минут, `completion_tokens` по способам.
