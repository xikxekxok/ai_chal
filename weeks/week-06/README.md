# Неделя 6

## Тема

**Локальные LLM:** Ollama, квантизация, сравнение с облаком, MCP + RAG на локальном контуре.

- Генерация **на своём железе** — приватно, без интернета, без платы за токен.
- **Сравнение** локальной (Ollama) и облачной (Dockhost) модели на одних запросах.
- **RAG + MCP** поверх локальной LLM; бонус — тумблер local ↔ cloud.

Лекция и правила: [week6_summary.md](../../.cursor/rules/lessons/week6_summary.md), [week-06.mdc](../../.cursor/rules/week-06.mdc).

**Особенность недели:** основной провайдер генерации — **Ollama**, не Dockhost; облако — для сравнения и бонуса.

**Железо:** Ryzen AI 7 350 + Radeon 860M (iGPU, 32 GB RAM). Дефолт модели — **`qwen3:8b`** (`OLLAMA_CHAT_MODEL`); лекционные 14B — stretch, не дефолт.
