# Week 2 Day 5 — бонус: живое интервью (LLM + LLM)

Копия [day-05](../day-05/) где демо — **настоящий диалог**: аналитик (тестируемый агент) и клиент (LLM).

## day-05 vs bonus

| | day-05 | day-05-bonus |
|---|--------|--------------|
| Агент | Секретарь (только фиксирует) | **Аналитик** (интервью, вопросы) |
| Клиент | Захардкоженный скрипт | **LLM** отвечает на реплики аналитика |
| Токены клиента | — | Off-books (`complete_silent`) |

## Запуск

```bash
python weeks/week-02/day-05-bonus/main.py --demo-compare-quick
python weeks/week-02/day-05-bonus/main.py --demo-compare
python weeks/week-02/day-05-bonus/main.py --clear --interview --strategy facts
```

## Как устроено

1. **Аналитик** (`agent.py`) — собирает ТЗ диалогом: уточняет, структурирует; стратегии контекста как в day-05.
2. **Клиент** (`client_sim.py`) — знает факты OpossumEats; по транскript + последней реплике аналитика генерирует ответ (не в `[tokens]`).
3. Ходы задают **сколько** реплик и мягкие hints (что ещё раскрыть), без дословного скрипта.
