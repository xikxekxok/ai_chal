# Неделя 2, день 2 (день 7 курса)

## Задание

Добавить агенту сохранение контекста:

- хранить историю диалога (`messages`) в JSON;
- при перезапуске загружать историю обратно;
- продолжать диалог так, как будто агент не выключался.

## Запуск

```bash
source .venv/bin/activate
pip install -r weeks/week-02/day-02/requirements.txt
cp .env.example .env   # если ещё нет; задать DOCKHOST_AI_KEY
```

One-shot (один ход, история сохраняется):

```bash
python weeks/week-02/day-02/main.py
python weeks/week-02/day-02/main.py "Объясни, что такое AI-агент, в двух предложениях"
```

Интерактивный чат с персистентностью:

```bash
python weeks/week-02/day-02/main.py --chat
```

Сброс истории перед новым прогоном:

```bash
python weeks/week-02/day-02/main.py --clear --chat
```

### Проверка персистентности (для видео)

```bash
# 1. Чистый старт
python weeks/week-02/day-02/main.py --clear --chat
# «Меня зовут Томми» → ответ → quit

# 2. Перезапуск — история должна загрузиться
python weeks/week-02/day-02/main.py --chat
# «Как меня зовут?» → агент вспоминает имя
```

При втором запуске в stdout: `[store] история: N сообщений (восстановлено из chat_history.json)`.

## Результат

Агент сохраняет и восстанавливает контекст между запусками. На видео: диалог → перезапуск → продолжение с памятью о прошлых сообщениях.
