# Неделя 1, день 4 — temperature

**Задание:** один промпт, три вызова с `temperature` 0 / 0.7 / 1.2, затем LLM-анализ ответов.

## Что сделали

- CLI `weeks/week-01/day-04/main.py`: sweep по температурам + 4-й вызов для сравнения и рекомендаций.
- Дефолтный промпт — юмористические лозунги в духе марксизма-ленинизма (хорошо видна разница креативности).
- Анализ на `temperature=0` для стабильных структурированных выводов.
- Флаги `--temp0` / `--temp07` / `--temp12` / `--no-analysis` для монтажа.

## Интересное

- Единственная переменная между тремя ответами — `temperature` в `extra_params`; промпт и модель одинаковые.
- Выводы «для каких задач» генерирует сама модель по фактическим ответам, не захардкожены в коде.

## Проблемы

- Запуск API в sandbox Cursor может падать по DNS (как в день 2); локально с `.env` — нормально.

## Вывод

Для сдачи: `python weeks/week-01/day-04/main.py` — показать три ответа, блок «СРАВНЕНИЕ» и «АНАЛИЗ» с рекомендациями.
