# Неделя 1, день 3 — четыре способа рассуждения

**Задание:** одна логическая задача, четыре стратегии промпта через Dockhost API.

## Что сделали

- CLI `weeks/week-01/day-03/main.py` на базе day-02: `--direct`, `--step`, `--meta`, `--experts`.
- Задача по умолчанию — «5 машин / 5 миль» (эталон: 5 минут).
- Meta: два вызова — генерация промпта, затем решение.
- Experts: три вызова с system-ролями (аналитик, инженер, критик).
- В консоль выводятся model, messages, extra_params, finish_reason, completion_tokens.
- Блок «СРАВНЕНИЕ» с эталоном и токенами по способам.

## Интересное

- Пошаговый и «критик» часто ловят ловушку «100 минут»; прямой ответ — нет.
- Meta-prompt даёт разный второй промпт от прогона к прогону — наглядно для видео.

## Проблемы

- Полный прогон — 7 API-вызовов; для монтажа удобнее флаги по одному способу.

## Вывод

Для сдачи: `python weeks/week-01/day-03/main.py --direct` … `--experts`, затем полный прогон или озвучить «СРАВНЕНИЕ».
