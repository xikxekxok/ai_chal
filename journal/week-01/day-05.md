# Неделя 1, день 5 — версии моделей

**Задание:** один промпт, три модели (слабая / средняя / сильная), метрики + LLM-анализ.

## Что сделали

- CLI `weeks/week-01/day-05/main.py`: sweep по `qwen3.5-9b` → `qwen3.5-35b-a3b` → `qwen3.7-max`.
- Замер `elapsed`, `prompt_tokens`, `completion_tokens`, стоимость по тарифам Dockhost.
- 4-й вызов — анализ на средней модели; блок «ССЫЛКИ» (docs, prices, HuggingFace).
- Промпт: уроки СССР для мирового пролетарского движения после революции — фокус на будущем, 3–4 урока кратко.
- Блок «АНАЛИЗ»: промпт к LLM в консоль не выводится (`show_messages=False`).

## Интересное

- `temperature=0` у всех трёх — различия только от модели, не от случайности.
- Слабая модель дешевле всего (14/20 ₽ за 1M токенов), сильная — в разы дороже (169/506).

## Проблемы

- Запуск API в sandbox Cursor может падать по DNS (как в дни 2–4); локально с `.env` — нормально.

## Вывод

Для сдачи: `python weeks/week-01/day-05/main.py` — три ответа, «СРАВНЕНИЕ», «АНАЛИЗ», «ССЫЛКИ».
