# Неделя 2, день 2 — персистентный контекст

**Задание:** сохранять историю диалога в JSON и восстанавливать при перезапуске.

## Что сделали

- `agent.py`: `load_history` / `save_history` → `chat_history.json`; `ChatAgent` загружает историю в `__init__`, сохраняет после каждого `run()`.
- `main.py`: `--clear` для сброса, `[store]` логи при загрузке/сохранении; `--chat` для ручного сценария с перезапуском.
- `chat_history.json` добавлен в `.gitignore`.

## Интересное

- Session memory из лекции: LLM сам не помнит — внешний JSON подмешивает прошлые `messages` в контекст при новом запуске.
- На втором one-shot прогоне `prompt_tokens` вырос (30 → 44) — видно, что история реально ушла в API.

## Проблемы

- Нет — smoke-test с Dockhost прошёл: сохранение 3 сообщений, восстановление, продолжение диалога.

## Вывод

Для видео: `--clear --chat` → имя/факт → quit → снова `--chat` → вопрос на память. В stdout при втором запуске: `[store] история: N сообщений`.
